# WhyCode Documentation

This folder contains the product and delivery documentation for WhyCode.

## Documents

| Document | Purpose |
| --- | --- |
| [WhyCode PRD](WhyCode_PRD.md) | Product requirements, scope, principles, and acceptance criteria |
| [Product Brief](product-brief.md) | Short product story, target users, value proposition, and MVP decisions |
| [UX Specification](ux-specification.md) | User journeys, screens, states, answer presentation, and accessibility requirements |
| [Technical Architecture](architecture.md) | System boundaries, request flow, integrations, and reliability expectations |
| [API Contract](api-contract.md) | Proposed HTTP endpoints, request shapes, response shapes, and error behavior |
| [Data Model](data-model.md) | Graph entities, relationships, provenance, identifiers, and indexing rules |
| [Evaluation Plan](evaluation-plan.md) | Evaluation questions, success metrics, acceptance checks, and demo preparation |
| [Implementation Plan](implementation-plan.md) | Dependency-aware delivery sequence and vertical slices |
| [Development Setup](development-setup.md) | Local prerequisites, start commands, indexing behavior, and available checks |

The PRD is the primary product document. The other documents provide more focused detail and should stay consistent with it.
