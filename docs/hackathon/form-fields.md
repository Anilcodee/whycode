## Your Problem Statement

Developers working with unfamiliar repositories can read what the code does, but understanding why it evolved requires manually connecting scattered commits, pull requests, issues and source files. WhyCode addresses this gap with evidence-backed repository investigation: users ask focused questions, inspect cited records and explore timelines and connections. When the indexed records do not establish a rationale, the system can withhold an unsupported explanation.

Short alternative if the field has a tighter limit:

Developers struggle to understand why unfamiliar code evolved. WhyCode connects code, commits and discussions into cited explanations, timelines and a repository tree, and can withhold answers when evidence is insufficient.
